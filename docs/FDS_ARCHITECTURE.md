DECISION RULES
--------------
Decision supports N-way branching.

MERGE RULES
-----------
Any node with incoming_count > 1 is a merge node.

CONNECTOR RULES
---------------
Connectors may be used for:

2. Long-distance continuation
3. Loopback continuation
